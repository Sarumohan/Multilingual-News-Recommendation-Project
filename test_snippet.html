System Abstract & Architectural Contribution: This dossier contains the verified source code implementation for the complete news recommendation framework. The architecture addresses two fundamental challenges in modern digital journalism: language under-representation (specifically regional Indic languages such as Assamese alongside Hindi and English) and unimodal content blindness. The framework integrates MiniLM-L12-v2 (384-d) with AI4Bharat IndicBERTv2 (768-d) for authentic script representation, ResNet-50 (2048-d) for visual feature extraction, and a Weighted Normalized Concatenation fusion layer yielding 2432-dimensional multimodal embeddings. Recommendations are synthesized through a hybrid content-collaborative engine governed by exponential temporal decay (λ=0.05) and Maximal Marginal Relevance (MMR) re-ranking (λ=0.70), delivering +84.89% category entropy gain, -66.67% redundancy reduction, and 4-factor Explainable AI (XAI) attributions.
